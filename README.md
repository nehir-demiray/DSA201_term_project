# AGN vs. Stellar X-ray Source Classifier

Binary classification of X-ray sources from the Chandra Source Catalog 2.1 (CSC 2.1) as AGN or stellar, using SIMBAD object-type labels as ground truth.

## Reproducing the Results

### Step 1 — Acquire data

**20k dataset** (default, `N_SOURCES = 20000`):
```bash
python query.py
# Output: data/csc21_simbad_enriched.csv
```

**5k dataset**: In `query.py`, change `N_SOURCES = 20000` to `N_SOURCES = 5000`, then run:
```bash
python query.py
# Rename the output manually:
mv data/csc21_simbad_enriched.csv data/csc21_simbad_enriched_5k.csv
```

### Step 2 — EDA and hypothesis testing

Open and run `dsa210_20k_eda_hypothesis.ipynb` with the 20k dataset in place:
```bash
jupyter notebook dsa210_20k_eda_hypothesis.ipynb
```
Plots are saved to `EDA_20k/`.

Similarly, for the 5k dataset, run:
```bash
jupyter notebook dsa210_5k_eda_hypothesis.ipynb
```

### Step 3 — Train and predict

```bash
python agn_stellar_classifier_20k.py
python agn_stellar_classifier_5k.py
```

Each script:
- Trains a Random Forest on SIMBAD-labeled AGN and stellar sources (75/25 stratified split)
- Evaluates on the held-out test set (classification report, confusion matrix, ROC AUC)
- Predicts on unlabeled sources (no SIMBAD match) and `other`-class sources
- Writes prediction CSVs to `outputs/`

## Features Used

| Feature      | Description                                      |
|--------------|--------------------------------------------------|
| `hard_hs`    | Hardness ratio (hard / soft band)                |
| `hard_hm`    | Hardness ratio (hard / medium band)              |
| `hard_ms`    | Hardness ratio (medium / soft band)              |
| `log_flux_b` | Log₁₀ of broad-band aperture flux               |
| `abs_glat`   | Absolute Galactic latitude \|b\|                 |

## Classification Scheme

SIMBAD object types are mapped to three classes:

- **AGN** — `AGN`, `Sy1`, `Sy2`, `QSO`, `BLL`, `G`, and related extragalactic types
- **stellar** — `*`, `WD*`, `XB*`, `CV*`, `Psr`, `V*`, and related stellar types
- **other** — any SIMBAD match not in the above sets (e.g. clusters, nebulae)
- **unlabeled** — no SIMBAD counterpart within 3″

The classifier trains on AGN and stellar only. Predictions on `other` and unlabeled rows are written separately.

## Notes

- `class_weight="balanced"` is used to handle the AGN/stellar imbalance.
- Flux is log-transformed before training; non-positive flux values become `NaN` and are median-imputed.
- Both classifier scripts are identical except for input/output file paths.
